# SourceHub (SourceHub.in) 🚀
### Modern B2B Omnichannel Retail Supply & Distribution Platform

SourceHub is a modern B2B retail distribution platform connecting FMCG brands, multi-city automated warehouses, walk-in cash-and-carry stores, and kirana retailers with AI demand forecasting, dynamic SPO pricing, and 100% EV-powered logistics.

---

## ✨ Key Features & Architecture

1. **Dynamic Background Video Hero**:
   - Seamless, high-performance background video showcasing real-world warehouse packing and fulfillment workflows.
   - High-contrast typography and fluid layout.

2. **Interactive SPO Pricing Engine & Flexible Packaging Units**:
   - Real-time calculator for volume discounts across Unit, Pack, Box, Carton, and Case.
   - Retail Partner Tiers: Silver (6%), Gold (12%), Platinum (18%).
   - Live retailer margin gauge and GST tax credit calculator.

3. **Hybrid Fulfillment Network (4 Specialized Formats)**:
   - **Mega Store**: Regional wholesale bulk depots (25,000 - 80,000 sq.ft.).
   - **Walk-In Store**: Direct physical cash & carry stores with digital POS barcode scanners.
   - **Pickup Store**: Click-and-collect smart lockers with 15-minute turnaround.
   - **Smart Micro Store**: Hyperlocal neighborhood fulfillment nodes powering 2.4-hr EV delivery.

4. **Dedicated Role Portals & Dashboards**:
   - **Retailers & Kirana Owners**: Active orders, credit line, 1-tap reordering.
   - **Warehouse Managers**: Conveyor throughput stats and simulated barcode scanner.
   - **Admin & Fleet Dispatch**: EV route clustering, telemetry, and live status.

5. **100% Green EV Logistics Fleet**:
   - Zero-emission electric commercial cargo vans and scooters.
   - Free same-day delivery for orders above ₹3,000.
   - Real-time carbon emission offset counter.

6. **Karnataka Hubs & Pan-India Footprint**:
   - Interactive SVG map featuring 7 operational cities: Bengaluru (HQ), Mysuru, Mangaluru, Hubballi, Shivamogga, Belagavi, and Tumakuru.

7. **Fully Mobile Responsive & SEO Optimized**:
   - Smooth responsive layout across all device viewports (320px to 4K).
   - Touch-friendly slide-down mobile navigation drawer with backdrop blur.

## 🚀 Running Locally

```bash
# Clone the repository
git clone https://github.com/shravyashetty04/SourceHub.git

# Navigate into directory
cd SourceHub

# Serve locally
npx serve -l 3000 .
# or
python -m http.server 3000
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
